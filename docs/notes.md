ML Methods in Educational Child-Robot Interactions
Educational Pose-Matching Social Robot
Ethan Xu, Scott Fukuda, Jiewen Liu*, Dr. Dongkuan Xu* and Dr. Peng Gao*

With the AI boom, developing an understanding of machine learning from a young age is increasingly important. Child-robot interaction in educational settings can be an effective tool for achieving cognitive and affective learning outcomes as they bolster engagement and provide a tailored learning experience. This project seeks to leverage child-robot interaction in K-12 AI education by building an interactive robot platform that teaches students about machine learning at a foundational level. This robot is part of an interactive lesson / demonstration that teaches children about ML by asking them to perform a gesture, matching the robot to their gesture, allowing the child to use voice commands to modify that gesture, and then storing that gesture under a name of the student's choice.

Thus far, we have
Design and implement full lesson pipeline (with processes communicating across devices using RESTful API / ROS)
Utilize an LLM to translate voice commands into robot movements
Experiment with different methods of human-to-robot gesture mapping (i.e. ML classification through MobileNet, mapping angles using MediaPipe landmarks)
Design and implement algorithms for features like selecting the most stable frame in a livestream and tracking a human subject with a camera.
“Next steps include”
Refine demo for superior user learning experience
Develop safeguards to prevent self-harming robot movements
Continue testing different methods of human-to-robot gesture mapping

The anticipated result of this work is a fully developed lesson that can be deployed for research in K-12 AI education.
